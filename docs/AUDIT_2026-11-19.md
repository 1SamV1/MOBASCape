# Project audit — 2026-11-19

Scope: the `rift/` workspace (the newest checkout; it contains the 5.6 map and
hero-select work). I rebuilt the client from source, captured the live frame,
and compared it against the reference video *"I made a RuneScape MOBA"*
(10xVisa, 11:11) at 60 s, 300 s, 420 s and 640 s.

## 1. Verdict

This is no longer a prototype. The cache reader, renderer, map generator,
hero-select flow, shop, HUD and combat sandbox are a coherent vertical slice.
The project's problem is **not missing technology** — it is that the match is
still a very good single-player tech demo wearing a developer HUD, while the
reference is a readable, networked 5v5 game.

Two facts matter more than any individual feature:

1. **There is no server and no authoritative match simulation.** `crates/sim`
   is a tile grid + A* library. Damage, gold, cooldowns, fog, waves, towers and
   win conditions live in `crates/client/src/animated.rs`. This violates the
   project's own north star and blocks every 5v5 goal.
2. **The reference's game feel comes from framing, contrast and feedback**,
   not polygon count. Our camera is too far and too shallow, the HUD reads as
   debug telemetry, and the base courtyard is grass instead of flagstone.

### Build note (important)

`target/release/rift-client` was stale (built 2026-11-15 from an older source
state) and rendered the castle wall solid red. A fresh `cargo build -p
rift-client` renders the wall white and correct. Do not evaluate the project
from old binaries; rebuild first. A reproducible build/CI step would have
caught this.

## 3. Reference vs. current build

What the video does that we should copy:

- **Framing.** Close, ~50–55° camera. Heroes are large on screen; the map reads
  as a place, not a minimap.
- **Scoreboard.** Top strip is only: blue kills, clock, red kills, personal
  K/D/A, CS. Everything else is contextual.
- **Team cards.** The right edge always shows the five enemy champions with
  portrait, level, HP and mana.
- **Objectives + target card.** The left side is a compact objectives panel and
  the selected/damaged unit's stats, not a permanent character sheet.
- **Base.** White crenellated wall, stone courtyard, central fountain, statues,
  obelisks. We already own every one of these assets; only the courtyard is
  missing.
- **Unit frames.** Name + level + wide HP bar above every hero, friendly ring
  blue and enemy ring red.
- **Feedback.** Big floating numbers, ground AoE telegraphs, kill shouts,
  minimap pings, buff icons with timers.

What we already do as well or better:

- Cache-native ground and 208 model textures, HDR bloom, real shadows.
- A fractured biome map instead of a plain OSRS map transplant.
- Deterministic pathing, collision, click-to-move and hold-to-steer.
- Shop with real item icons, remote purchase and courier delivery.
- Hero select with baked cache-model portraits.

## 4. Gap list (ordered by blocking power)

| # | Gap | Consequence |
|---|---|---|
| G1 | No authoritative combat sim / server | Cannot add real players, reconnect, replay, or anti-cheat |
| G2 | HUD is debug telemetry | New players cannot read the match; the reference's identity is lost |
| G3 | No audio at all | Every hit, cast and kill is silent; game feel is capped |
| G4 | Camera/lighting too flat | World looks like a diorama; heroes are small |
| G5 | Base courtyard unpaved, lanes sparse | Bases and lanes do not read as MOBA spaces |
| G6 | One map, four champions, shallow items | Content ceiling far below the reference |
| G7 | No results/lobby/queue flow | The match has no beginning or end |
| G8 | Unit frames and VFX thin | Combat is hard to parse in a teamfight |
| G9 | No CI / headless match tests | Regressions like the red wall ship silently |
